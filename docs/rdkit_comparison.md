# chematic vs RDKit — 定量比較レポート

**作成日**: 2026-05-27  
**chematic バージョン**: 0.1.1  
**RDKit バージョン**: 2024.x (Python)  
**比較分子数**: 175 分子（diverse set: 有機小分子・アミノ酸・複素環・天然物・FDA 承認薬）

---

## 概要

chematic の各プロパティ計算結果を RDKit のリファレンス値と比較した。
MW・HAC・HBD・TPSA は高精度；LogP は簡略化 Crippen テーブルの制約から中程度の精度；
ECFP4 Tanimoto 類似度は順位相関 ρ=0.92 と実用的な精度を示す。

---

## 1. 物性値精度（n=175 分子）

### 統計サマリー

| プロパティ | MAE | RMSE | Pearson r | 評価 |
|-----------|----:|-----:|----------:|------|
| 分子量 (MW / Da) | 0.0002 | 0.0007 | 1.0000 | ✅ 実質完全一致 |
| 重原子数 (HAC) | 0.000 | 0.000 | 1.0000 | ✅ 完全一致 |
| 水素結合ドナー (HBD) | 0.011 | 0.107 | 0.9974 | ✅ 優秀 |
| TPSA (Å²) | 1.33 | 4.96 | 0.9925 | ✅ 優秀 |
| 水素結合アクセプター (HBA) | 0.606 | 1.014 | 0.9321 | 🟡 良好 |
| LogP (Crippen) | 1.346 | 1.766 | 0.4561 | 🔶 制限あり |

### 注記

**MW**: 差異は原子量の平均同位体質量の端数（±0.002 Da）のみ。計算アルゴリズムは正確。

**HAC / HBD**: 完全一致または誤差が 1 件未満。

**TPSA**: Ertl 2000 原子タイプ表を忠実に実装。主な残留誤差源：
- アミド N の文脈依存的貢献（RDKit は SMARTS ベースの N 分類を実施）
- 一部の複素環 N の芳香族性認識差異（例: ジヒドロピリミジノン環）
- 最大外れ値: thiamine (Δ+9.0)、sildenafil (Δ+6.1)、atorvastatin (Δ+8.0)

**LogP**: 簡略化 Crippen テーブル（約 10 原子タイプ）を使用。全 Wildman-Crippen モデル（68 原子タイプ）には及ばない。  
主な誤差源: 塩素/硫黄化合物の疎水性過小評価、電荷 N の過大評価。改善には SMARTS ベースの原子タイプ分類が必要。

## 3. ECFP4 Tanimoto 類似度（n=2450 ペア, 50分子サブセット）

| 指標 | 値 |
|-----|----|
| MAE (Tanimoto) | 0.0146 |
| RMSE (Tanimoto) | 0.0291 |
| Pearson-r | 0.9538 |
| **Spearman-r（順位相関）** | **0.9173** |
| \|ΔTanimoto\| p90 | 0.044 |
| \|ΔTanimoto\| p99 | 0.109 |

### 評価

- **Spearman r=0.917** は実用上十分な精度。類似化合物ランキング・スクリーニング用途に適合。
- 差異の主因: ハッシュ関数の違い（chematic は FNV-1a 64bit; RDKit は Morgan アルゴリズム由来の独自ハッシュ）。同じ Morgan 半径でも bit 位置が異なるため、Tanimoto の絶対値は若干ずれる。
- **順位一致性 (Spearman r>0.9)** が仮想スクリーニングに重要な指標であり、これは十分に達成されている。

## 4. アルゴリズム実装メモ

### MW
- 平均同位体質量テーブル（118 元素）を使用。
- 暗黙的 H: OpenSMILES §3.4 規則（1.5 per aromatic bond）で計算。

### TPSA (Ertl 2000)
- N: 一次/二次/三次アミン、芳香族 N±H を区別。
- O: OH (20.23), 芳香族 O (13.14), カルボニル O (17.07), エーテル O (9.23), S=O O (0.0)。
- S: 芳香族 (28.24), SH (38.80), チオエーテル (25.30), スルホキシド (36.28), スルホン (42.52)。
- P: 非芳香族 (34.14)。

### LogP (簡略化 Crippen-Wildman)
- ~10 原子タイプテーブル。MAE≈1.35（RDKit 比）。
- 改善計画: SMARTS ベース 68 原子タイプへの拡張（Phase 7 候補）。

### ECFP4
- Morgan 半径 2 (ECFP4)。
- 原子不変量: 原子番号・電荷・次数・H 数・環内・芳香族フラグ。
- FNV-1a 64bit ハッシュ、BitVec2048 (2048 ビット)。

## 5. 再現手順

```bash
# 1. RDKit reference 生成（Python + RDKit 必要）
python3 scripts/gen_rdkit_reference.py

# 2. chematic 比較実行
cargo run -p chematic-chem --example rdkit_compare --release
```

出力ファイル:
- `scripts/rdkit_ref_properties.tsv` — RDKit リファレンス値（175 分子）
- `scripts/rdkit_ref_tanimoto.tsv`   — RDKit ECFP4 Tanimoto 行列（50×50）
- `scripts/chematic_vs_rdkit.tsv`    — chematic vs RDKit 対比表（全プロパティ）
