# v1.0 independent security review packet

This packet is prepared for a maintainer who is not the author of the change
under review, or for an external auditor. It is review input, not evidence
that an independent review has already happened.

## Review scope

Review the following boundaries at the v1.0 candidate revision:

- text and structured parsers: SMILES, SMARTS, MOL/SDF V2000/V3000, MOL2,
  CML, CJSON/MolJSON, CDXML, reaction formats, and XYZ/PDB paths;
- serializers and round trips, including unknown-field preservation,
  malformed-record handling, output-size limits, and typed rejection;
- Python/PyO3, WASM, and Node-hosted WASM contracts, including panic/error
  translation, byte/atom/result limits, JSON decoding, and output bounds;
- filesystem, process, and network behavior reachable through the reviewed
  binding and CLI surfaces;
- resource exhaustion, integer conversion, recursion/depth, allocation,
  timeout, and cancellation behavior at each boundary.

## Required reviewer actions

1. Review `docs/security-surface.md`, `SECURITY.md`, the checked-in workflows,
   and the public boundary code listed above.
2. Run the repository-local gate from a clean checkout:

   ```text
   python3 scripts/security_review_gate.py
   python3 scripts/check_workflow_pins.py
   python3 scripts/check_unsafe_surface.py
   ```

3. Run the relevant Rust, Python, and Node/WASM adversarial contract suites;
   record exact commands, toolchain versions, source revision, and results.
4. Attempt at least one negative test in each scope area, including oversized,
   truncated, deeply nested, malformed, and cross-binding inputs.
5. Record every finding with severity, affected revision/API, reproduction,
   exploitability, disposition, regression test, and residual risk.

## Acceptance criteria

The reviewer may sign off only when there is no unclassified high/critical
finding, reproducible crash, unexplained resource exhaustion, or unreviewed
boundary change. A clean local gate is supporting evidence and does not replace
the independent review.
