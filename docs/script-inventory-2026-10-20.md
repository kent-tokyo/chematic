# Maintenance script inventory (2026-10-20)

This is a path and reference audit of `origin/main` at `e842ae41`, followed by
the first layout cleanup. It is not a claim that every historical script is
still executed. `scripts/README.md` describes the retention policy and main
entry points.

| Measure | Before | After this cleanup |
|---|---:|---:|
| Tracked files under `scripts/` | 597 | 593 |
| Direct children of `scripts/` | 516 | 512 |
| Files under `scripts/tests/` | 81 | 81 |
| Files with a literal `scripts/<path>` reference outside `scripts/` | 588 | 586 |
| Files with a literal path reference in `.github/workflows/` | 103 | 103 |

The reference counts are sets of existing tracked paths, not counts of calls.
Many matches come from frozen benchmark JSON source-hash maps that list nearly
every script. They are provenance, not evidence that a script is still used.
Excluding data files and the new baseline list, 155 original root files had no
literal path reference outside `scripts/`. Some are still imported, invoked by
basename, used manually, or needed to regenerate committed fixtures. Active CI
and some reproduction instructions use exact paths, so a mass move would break
them.

## Files without a literal path reference outside `scripts/`

Before this cleanup there were nine:

- `freeze_trust_holdouts.py` selects outcome-blind inputs for the committed
  `validation/trust_holdouts/v1` packet. It now lives beside that packet at
  `validation/trust_holdouts/freeze.py`; its output path is unchanged.
- `rdkit_standardization_classification.py` is imported by
  `rdkit_cleanup_parity.py` and `rdkit_cleanup_source_gate.py`. It is retained.
- Seven files in `scripts/tests/` are test modules. Five were already invoked
  by module name in CI. This cleanup adds the other two to the Test job, after
  converting `test_changed_public_crates.py` to `unittest`. A path-only scan is
  not grounds for deleting tests.

## Removed diagnostics

- `analyze_logp_mismatches.py` relied on a local `~/Downloads/SMILES.csv` and

  issue reference and no committed result to regenerate.
- `aromaticity_mechanism_probe.py` likewise used a local CSV and printed an

Frozen benchmark JSON source-hash maps are unchanged; Git history preserves
these scripts at the original revisions. Other candidates still need a
purpose-by-purpose review before deletion. The direct-child list is frozen in
`tools/script_root_baseline.list`; `tools/check_script_layout.py` rejects new
unlisted direct children and unknown subdirectories. New scripts go into a
purpose-specific subdirectory. Moving a retained script requires updating its
CI and documentation references, imports, and repository-root resolution.

## Follow-up organization

The subsequent cleanup moves all 28 `generate_*_boundary_fixtures.py` scripts
to `scripts/generators/` and 21 retained diagnosis, probe, and audit scripts to
`scripts/diagnostics/`. Their output destinations remain under `validation/`;
the pinned fixture data and frozen benchmark JSON were not regenerated.
Current CI, source-example, benchmark, and validation instructions use the new
paths. The Python test importing `probe_rdkit_python_contract.py` and the
descriptor classifier importing `tpsa_functional_group_probe.py` now use the
new module locations.

`mmff94_macrocycle_type_audit.py` was a one-off stdout-only comparison with
no current reference or retained output. The broader
`mmff94_atom_type_census.py` remains available for row-accounted RDKit atom
type comparisons, and dedicated MMFF regression tests remain in place. The
root baseline falls from 512 to 462 files. With two directory READMEs and
that deletion, `scripts/` now contains 594 tracked files after this follow-up.

## Broader script organization

A second pass moves another 29 corpus, fixture, and report generators to
`scripts/generators/`, three release artifact generators to `scripts/release/`,
and 19 retained MMFF94 evidence scripts to `scripts/diagnostics/`. The active
workflow commands, importing tests, source examples, and reproduction paths
follow the new locations. Pinned outputs and source-hash records are not
regenerated by the move.

`mcs_rdkit_fmcs_diff.py` is removed. It printed an unrecorded exploratory
comparison, had no CI or reproduction reference, and pointed to a missing
parked-note file. Its stated atom-comparator gap is superseded by the current
comparator tests and documentation. This pass brings direct `scripts/` children
to 410; adding `scripts/release/README.md` offsets the deletion, leaving 594
tracked files under `scripts/`.

A third layout pass moves 57 standalone `validate_*` entry points and their
Node drivers into `scripts/validation/`. It updates referenced commands and
source-hash manifests, fixes the one shared-helper import, and resolves WASM
module arguments before Node loads them. The root baseline is now 353 files;
one directory README brings the `scripts/` total to 595 tracked files. No
fixture or measured result was regenerated by this layout change.

The remaining root includes active CI checks and benchmark runners with
cross-script imports. The baseline prevents new root entries while those
families are migrated with their own call-site and test review.
