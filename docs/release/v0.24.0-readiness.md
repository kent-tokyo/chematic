# v0.24.0 readiness

This is the release gate for the Phase 2 tautomer and canonicalization work.
It is intentionally kept separate from the changelog: a release note records
what shipped, while this file records what must be true before the version is
renamed to `0.24.0`.

## Current status

The Phase 2 implementation and regression suite are green. The former two
structural-equivalence gates were re-audited against RDKit InChIKeys and each
contained a positional isomer mislabeled as a tautomer. With those fixture
variants corrected, the gates are closed:

| Gate | Status | Required evidence |
| --- | --- | --- |
| `tp2-39` asymmetric methylpyrimidinone | Closed | Corrected same-identity keto/enol spellings converge under the general dual-flank implementation. |
| `tp2-holdout-06` N9-methylhypoxanthine | Closed | Corrected held-out keto/enol pair converges using the same general rule. |

The following independent limitations are explicitly accepted for v0.24.0
under the policy below. They are not release blockers, but remain documented
follow-up work:

| Gate | Status | Evidence required |
| --- | --- | --- |
| Canonical SMILES E/Z spelling normalization | Accepted exception | Direction-only spelling variance is accepted when round-trip identity and E/Z assignment are preserved. |
| CIP precision | Accepted exception | Legacy approximate CIP remains supported; accurate mode and typed unresolved results are available for callers requiring stronger guarantees. |
| Aromaticity-context gap | Accepted exception | The known perception residual is excluded from the v0.24 contract provided it cannot silently change chemical identity. |

The implementation exposes the safe exocyclic lactam/lactim edge in both
directions and rejects candidates that fail kekulization; it does not claim
that arbitrary positional isomers are tautomerically equivalent.

## Accepted v0.24.0 exceptions

The following are explicitly outside the v0.24.0 correctness contract and do
not block the release:

- E/Z direction-only spelling differences are accepted when parse → canonical
  SMILES → parse preserves the same E/Z assignment and molecular identity.
- The legacy CIP engine remains approximate. Callers requiring the stronger
  guarantee must use the additive `CipMode::Accurate` API; unresolved centers
  are reported through `CipModeAssignment::unresolved` rather than guessed.
- The aromaticity-context residual remains a known perception limitation. It
  must not silently alter connectivity, valence, stereochemistry, or isotope
  identity; affected cases remain documented for a later dedicated fix.

These exceptions are release policy, not claims that the three limitations
are fixed. They are paired with the measured regression suites and the
fail-closed behavior above.

## Passing evidence already present

- `tp2-05`/`06`/`08`: 2-pyridone, 4-pyridone, and uracil convergence.
- `tp2-07`/`09`: cytosine and guanine dual-flank convergence.
- `tp2-holdout-01`: primary hypoxanthine convergence.
- Corrected identity audit for the two affected holdout cases is preserved in
  `validation/tautomer_parent_identity_phase2_holdout_corrected.jsonl`.
- `tp2-04`: nitroso/oxime convergence without unrelated ketone enolization.
- Explicit-H, isotope, stereo, blocked-site, invalid-valence, and reverse-edge
  regressions in `crates/chematic-chem/src/tautomer.rs`.
- Python and WASM `tautomer_parent` bindings and JSON/status regressions.

## Required final commands

Run these before the version bump and package/publish audit:

```text
cargo fmt --all -- --check
cargo check --workspace
cargo test --workspace --lib
cargo clippy --workspace --all-targets -- -D warnings
git diff --check
```

Only then should workspace and pinned intra-workspace dependency versions be
bumped from `0.23.0` to `0.24.0`, followed by a clean publish/package audit.
