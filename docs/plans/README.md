# Plans and maintenance contracts

This directory groups forward-looking design and maintenance documents that
remain active but are not API reference pages.

- Accuracy plans define bounded targets, not completed parity claims.
- The refactoring plan defines current repository guardrails.

Completed historical audits remain in the
[repository archive](https://github.com/kent-tokyo/chematic/tree/main/docs/archive),
while current user-facing behavior belongs in the relevant reference page.
