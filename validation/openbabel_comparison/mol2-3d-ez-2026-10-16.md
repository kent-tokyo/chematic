# Open Babel 3.2.1: 3D MOL2 alkene geometry

## Scope and inputs

This check measures MOL2-to-SMILES preservation of molecular identity and
double-bond E/Z. It is separate from tetrahedral chirality, format coverage,
speed, and chemical property prediction.

The 12 committed MOL2 files in `crates/chematic-mol/tests/data/mol2-3d-ez-*.mol2`
cover paired geometric isomers of difluoroethene, butene, substituted
haloalkenes, a conjugated diene, an oxime, and a trisubstituted alkene.
RDKit 2025.09.3 embedded explicit-H 3D coordinates from the source SMILES
listed in `check_mol2_3d_ez.py`, using seeds `20261016 + case_index`.
RDKit wrote V2000 MOL; Open Babel 3.2.1 converted each MOL to Tripos MOL2.
The comparison feeds the same committed MOL2 bytes to both readers and
canonicalizes their SMILES with RDKit. The script reports each fixture's
SHA-256 and compares the complete canonical isomeric SMILES, including graph,
charge, and E/Z, against the source SMILES.

An optional holdout generates another five conformers per source with seeds
`400000 + seed_index * 100 + case_index`, checks that RDKit rereads each
intermediate MOL as the source isomer, and again feeds the same generated
MOL2 to both readers.

## Result

| Input | CheMatic | Open Babel |
| --- | ---: | ---: |
| 12 pinned MOL2 files | 12/12 | 12/12 |
| 60 newly embedded holdout MOL2 files | 60/60 | 60/60 |

The parent main commit `25e5c76c` recovered tetrahedral configuration from
3D MOL2 but had no E/Z perception in either MOL2 reader. The new reader path
compares the two alkene substituent vectors perpendicular to each double-bond
axis. It leaves collinear or nearly orthogonal geometry unspecified, preserves
the existing shared-carrier conflict handling, and works on planar molecules
and rotated conformers. The Rust test checks both MOL2 readers, opposing
isomers, rotation, degenerate geometry, and the existing tetrahedral cases.

## Reproduction

From the repository root, with RDKit and Open Babel installed:

```sh
cargo build -p chematic-cli
python3 validation/openbabel_comparison/check_mol2_3d_ez.py \
  --cli "$(pwd)/target/debug/chematic" --holdout > mol2-3d-ez-results.json
cargo test -p chematic-mol --test mol2_3d_stereo
```

The generated JSON contains individual source, fixture hash, output, and
pass/fail rows. This is a focused parity result on 12 molecular structures
and 72 conformers. It does not establish Open Babel-wide superiority.
