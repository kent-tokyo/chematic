# V2000 isotope output

Original synthetic MIT fixtures in `cases.json` distinguish natural-abundance
atoms from explicitly labelled isotopes. Fifteen ordinary cases are scored
separately from four hypothetical mass-number storage controls. Expected
atomic numbers, formal charges, isotopes, atom maps and indexed bonds are
authored, not generated by either runtime's reader.

See [the full contract and limits](../../docs/reference/v2000-isotope-output.md).
Baseline `342d1d5f` has the same affected production files as the candidate's
parent `90014be5`. Python and Node WASM baseline artifacts are retained apart
from candidate artifacts; never overwrite a baseline runtime during rebuilding.
Use the Cargo.lock-pinned `wasm-bindgen` version (0.2.129 in this run).

With RDKit 2025.09.3, Node, and Open Babel 3.2.1 at `/opt/homebrew/bin/obabel`:

```sh
PYTHONPATH=/path/to/baseline-python python3 scripts/validation/check_v2000_isotope_output.py \
  --wasm-module /path/to/baseline-wasm/chematic_wasm.js \
  --baseline --runtime-revision 342d1d5f9ad09aa6ade4e3079a902cba856209e2 \
  --output validation/results/v2000-isotope-output-baseline-2026-10-24.json.gz
PYTHONPATH=/path/to/candidate-python python3 scripts/validation/check_v2000_isotope_output.py \
  --wasm-module /path/to/candidate-wasm/chematic_wasm.js \
  --output validation/results/v2000-isotope-output-candidate-2026-10-24.json.gz
python3 -m unittest scripts.tests.test_v2000_isotope_output -v
```

The reports retain every source SMILES, expected field, generated block,
observation, command, process terminal result and tool/artifact/source hash.
Their candidate `runtime_revision=working_tree` and `head` describe a pre-commit
measurement; verify `production_sources` hashes against the committed files.
Each subprocess has a 10-second/1-MiB bound. Empty output, process failures or
unreadable output cannot pass the preservation gate.

The gate is field preservation plus narrow isotope layout, not complete
CTfile/chemical validity, implicit hydrogen or stereo correctness, geometry
precision or performance. Storage controls include hypothetical masses and
do not imply physical validity. Open Babel with documented `-xa` preserves
all 19 controls; report it alongside the default profile.
