# E/Z CIP labels on the exposed 10,000-molecule corpus

This is a bond-level stereochemistry comparison, not a claim that one toolkit
is generally more accurate. RDKit's CIP labeler supplies the expected E/Z
descriptor for each double bond. CheMatic and COSMolKit parse the original
SMILES independently; bond endpoint atom indices identify each label. A
missing, wrong, or extra label fails the comparison.

## Fixed inputs

- Corpus: `validation/benchmark_corpora/rdkit-js-browser-10k-v1.smi`, SHA-256
  `f48777e96f74738336f47f682fbff5af6775a3474fe25daa28b595340feee95f`.
- 10,000 RDKit-parseable molecules; 572 contain 780 E/Z-labeled double bonds.
- RDKit 2025.09.3; COSMolKit 0.5.0; source-built CheMatic from this change.
- Comparison: `check_ez_cip.py`, using
  `crates/chematic-chem/examples/ez_cip_dump.rs` for CheMatic.

| Engine and mode | Before | After | Missing / extra labels after |
| --- | ---: | ---: | ---: |
| CheMatic default CIP | 770 / 780 | 780 / 780 | 0 / 0 |
| CheMatic accurate CIP | 780 / 780 | 780 / 780 | 0 / 0 |
| COSMolKit CIP | 780 / 780 | 780 / 780 | 0 / 0 |

The ten default-mode errors before this change were rows 1054, 1206, 1213,
1214, 1287, 1370, 1371, 2316, 2371, and 2466 (zero-based). All have an
aromatic substituent at an E/Z bond end. The legacy sphere comparison did not
account for duplicate atoms contributed by aromatic multiple bonds, reversing
the priority of two substituents. The default path now uses the existing
hierarchical CIP ranker for such bonds when it can resolve them; aliphatic
bonds retain their existing path. The distinct accurate mode still handles
tetrahedral CIP and explicit abstentions separately.
The source-built before/after dumps contain 1,560 label rows each; exactly
these ten default-mode rows changed, and the other 1,550 rows stayed identical.

The baseline was source-built from main commit `19f07cd1`; its raw CheMatic
dump SHA-256 was
`66d3fd4a4232fbccc3667c75edfc4a9f80b4df5e411dfaf03e76e6cc4bdae729`.
The candidate raw dump SHA-256 was
`4dd48754c55ad049063839c5e9819880b3e57feab210c916ce0cf2e84daa800b`.
The candidate binary SHA-256 was
`412a024a34a3f8e9497c9a12d5a5c092b705971d943b39906dac89fd0888ed74`.

## Reproduction

```sh
cargo build -p chematic-chem --example ez_cip_dump --offline
/path/to/python-with-rdkit-and-cosmolkit \
  validation/cosmolkit_comparison/check_ez_cip.py \
  --corpus validation/benchmark_corpora/rdkit-js-browser-10k-v1.smi \
  --chematic target/debug/examples/ez_cip_dump
```

The fixed corpus reaches parity with both comparison toolkits. It does not
measure other CIP classes, unseen molecules, or all format readers; no general
accuracy superiority follows from these numbers.
