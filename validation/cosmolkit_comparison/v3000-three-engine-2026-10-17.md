# V3000 explicit-hydrogen recognition: three-writer comparison

**Method correction:** The [normalized-input follow-up](v3000-radical-stereo-2026-10-17.md)
supersedes this report's three-writer score. On `stress-line-3524`, the
original method gave CheMatic raw `[H]=C` text while RDKit's writer received
RDKit's normalized molecule. The follow-up feeds every writer the same
normalized SMILES and retains this report as historical evidence.

This is a **development-corpus** SMILES → V3000 → RDKit read-back comparison.
The same RDKit reader judges the exact canonical isomeric identity of each
writer's output against the source molecule. Atom-map numbers are removed from
both identities. A refusal, unreadable block, or changed stereochemistry is a
miss. This measures the stated interchange path, not independent chemical
truth or toolkit-wide accuracy.

The CheMatic candidate has one miss, `stress-line-3524`, whose source has a
double-bonded explicit H. RDKit has five misses and COSMolKit four on this
corpus. In particular, both external V3000 writers change `stress-line-3403`:
the ring alkene changes configuration, while the source's Zn stereotag remains.
Before this change, CheMatic kept that alkene but lost the Zn tag because its
V3000 atom line omitted `VAL=4`. With `VAL=4`, RDKit rereads both correctly.

RDKit 2025.09.3 as the reader gives 315/316 for CheMatic, 312/316 for
COSMolKit and 313/316 for RDKit. Against the CheMatic source at `d03106b5`,
the candidate gains one exact row (314 → 315) and regresses none on this

## Reproduction

```sh
cargo build --offline -p chematic-cli
python scripts/compare_rdkit_cosmolkit_v3000.py \
  --cli target/debug/chematic \
  --report /tmp/v3000-three-engine.json
```

Run the script in a Python environment containing the named RDKit and
COSMolKit versions. The JSON report records versions, corpus and CLI hashes,
every source identity, every reread identity, and per-engine block hashes.
