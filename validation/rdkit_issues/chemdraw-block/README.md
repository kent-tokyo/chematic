# Authored ChemDraw binary recipes

Generated by `scripts/generate_chemdraw_fixtures.py` from literal molecular
graphs. No upstream attachment is copied. CDXML counterparts are assembled
independently from the same literals, rather than using the candidate decoder.
All non-carbon atoms in the comparison corpus carry explicit H counts to keep
that policy separate from default valence inference.

The 22-byte header is observed in RDKit 2026.09.1's `structure_1.cdx`; the
28-byte header is described in the vendor SDK. The supported profile and
refusal conditions are in `docs/chemdraw-block.md`.

With freshly built Python and Node WASM modules, plus RDKit 2026.09.1:

```sh
python3 scripts/validate_chemdraw_block.py --wasm-module /path/chematic_wasm.js --output /tmp/chemdraw-evidence
```
