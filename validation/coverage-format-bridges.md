# Format bridges and UFF boundary coverage

This change retains the existing coverage workflow targets, ignores, thresholds,
and exclusions. Native reference data come from the pinned RDKit 2026.03.1
wheel. Rust tests read committed JSON and require no RDKit installation or
network access.

## CDXML correction

The molecule reader previously scanned physical lines and silently returned an
empty graph for a valid minified document containing several tags on one line.
It now reuses the document editor's logical XML records. Physical input line
and byte limits are still checked before tokenization in the molecule reader.
The editor's existing logical-record limit semantics are unchanged.

The shared splitter respects quoted `>` characters and multiline attributes.
Comments, CDATA, and processing instructions remain opaque, so apparent atom
tags in those records cannot create phantom atoms. Tests compare fragment order,
coordinates, and molecular graphs before and after minification; check the
physical-line budgets; and preserve the document reader's original source.
This is not a general XML validator or a DTD implementation. Aromatic CDXML
round trips compare compressed and uncompressed reader results: CDXML bond
orders alone do not restore the SMILES parser's atom aromaticity flags.

## Native reference contracts

- 45 UFF evaluations cover 15 parameterized molecules with distorted, collinear,
  and coincident coordinates, including small rings, inversions, separated
  fragments, and linear bonds. All energies and gradient components must match
  native RDKit within `1e-7 + abs(reference) * 1e-9` for finite values. Native
  NaN and infinity classifications are recorded explicitly for degenerate
  inputs; 13 energies are nonfinite. These geometries do not represent usable
  minima. Distorted, finite geometries additionally check every gradient
  component against a central finite difference with step `1e-6` and tolerance
  `1e-3 + abs(gradient) * 2e-5`.
- 874 molecular hashes cover 46 charged, radical, isotope, unusual bond-order,
  and conjugated structures across all 19 native default hash functions. The
  empty graph uses `MoleculeBuilder`, consistent with the SMILES parser's
  intentional rejection of an empty input string. These are non-CX hashes;
  native CX scaffold hashing can raise an internal output-order `KeyError`
  when the hash creates an empty graph and is not frozen as a successful result.
- 36 Tripos MOL2 inputs compare phosphate/quaternary-nitrogen cleanup with
  both bond endpoint orders and cleanup enabled/disabled. Six inputs are
  rejected by the native reader, and Rust must reject them too. Reference
  results are measured from the generated block, including its atom types,
  rather than copied from the generator's starting SMILES.

## Public interchange contracts

QCSchema tests cover converter index/symbol errors, charge/multiplicity and
coordinate preservation, and numeric bond-order conversion. CJSON tests check
implicit single orders, negative indices, malformed JSON, required fields,
and string limits. LAMMPS DATA tests preserve atom image flags and velocities
and reject integer overflow, truncation, and unsupported atom styles.

MRV tests cover entity-decoded bond stereo diagnostics and writer rejection
of a deliberately unkekulizable graph without modifying its source. MOL2 tests
preserve edited formal charges alongside partial charges, atom/bond status
bits, opaque sections, unknown UNITY attributes, and metadata tails; malformed
attribute fields report the actual offending field. XYZ tests preserve string
and logical properties and verify terminal parse errors, batch completion, and
cancellation before another frame is read. V3000 tests round-trip query bonds
through both 2D and conformer writers, retain R-group labels, and diagnose
malformed coordinates and incomplete blocks. Query records are interchange
objects, not assertions of physically valid force-field molecules.

## Reproduction

Install the pinned `rdkit==2026.03.1` wheel and set `PYTHONPATH` accordingly.
Run `scripts/generate_hash_ions_boundary_fixtures.py`,
`scripts/generate_mol2_ionic_boundary_fixtures.py`, and
`scripts/generate_uff_geometries_boundary_fixtures.py`. Each generator checks
the native version. All three fixtures regenerated byte-identically.

## Validation result

After `cargo llvm-cov clean --workspace`, the complete unchanged coverage
command passed 5,401 tests (9 ignored) across 101 test executables. LCOV records
155,524 of 161,949 lines in 340 files: 96.032702% locally. This is a macOS
source measurement. The Linux workflow upload and processed Codecov main report
remain authoritative for the published percentage. Workspace all-target Clippy
(`-D warnings`), formatting, and `git diff --check` passed.
