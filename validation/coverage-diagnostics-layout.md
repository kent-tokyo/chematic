# Diagnostic, layout, and format boundary coverage

This follows #811 (processed Linux Codecov: 95.24%) with unchanged coverage scope and exclusions.

- Drawing: reverse atom/bond order while retaining each original atom's coordinates and 1.5 Å bond lengths; use the public drawing callback to round-trip carbon tetrahedral stereo and alkene E/Z through MOL. The callback round trips do not cover lone-pair centres. General permutation parity agrees with an independent inversion count for sizes zero through nine.
- Stereo diagnostics: violations retain the exact atom/bond identities; ring-torsion applied/scored-only counts agree with real pipeline evidence. The 2D assignment test now uses one unambiguous wedge, independently checked with RDKit 2026.03.1 as S and R after reflection, and verifies that applying the assignment updates only the centre.
- Errors: actual conformer, bond-perception, O3A, 3D-descriptor, XYZ, and condensed-formula failures retain the relevant value or cause in their display messages. Failed conformer insertion leaves the ensemble empty.
- Reaction inputs: a private helper accepts the existing parse limits so boundary/over-limit tests stay small; production passes the same default limits. Test component grouping with branches/recursive SMARTS, explicit-H product spelling and unsupported primitives, and the four-match Cartesian-product boundary before any products are generated.
- Morgan fingerprints: linear alkanes with 128/129/130/256 atoms and cyclic alkanes with 128/129/130 atoms straddle the 128-bond specialization limit. Detailed, direct, and prepared results agree with independently measured RDKit 2026.03.1 bits (radius 2, 2048 bits, default suppression/bond types, chirality off). Repeated prepared evaluation is stable.
- Ewald fallback: the infinite-cutoff sum agrees with an analytic three-charge result; non-finite coordinates retain the guarded valid pair; the damped API follows its documented direct-sum fallback.
- Chemistry helpers: BRICS size thresholds exclude attachment wildcards; biphenyl's direct scaffold parent is benzene and single-ring/acyclic inputs stop. Cube-to-molecule conversion keeps grid coordinate units and does not turn nuclear charge into formal charge.
- MOL2 reference: 84 records, all eight sanitize/remove-H/Corina-cleanup combinations (672 outcomes, 668 accepted by RDKit). New records cover charged guanidinium/carboxylate patterns and collinear/coincident controlling substituents on both double-bond ends, including reversed bond endpoints. Expected outcomes come from the reader, not the original source SMILES.
- PDB reference: 976 outcomes (948 accepted), adding CRLF, a one-character element at line end, multiple MODEL records, bidirectional double/triple CONECT, occupancy/B-factor errors, and alternate locations.

Validation: the unchanged full coverage command passed 5,350 tests, nine ignored and zero failed, including native InChI and loopback HTTP. After expanding the format references, the complete SMILES library passed 355 tests with one ignored. Workspace all-target Clippy and formatting pass. A fresh coverage build is used for the final local measurement: iterative reports can contain compiled mappings from earlier source layouts, so processed Linux Codecov is the service-percentage evidence.
