## Throughput (Python API, `bulk.*`)

### Same fixture as the 2026-06 snapshot (`scripts/benchmark_vs_rdkit.py --rdkit`)

20 small drug-like SMILES cycled to fill each N; RDKit uses the deprecated
`GetMorganFingerprintAsBitVect` (same call the script has always used).

| N | chematic (Rayon parallel) | RDKit (Python loop) | Speedup |
|---|---------------------------|----------------------|---------|
| 100 | 13.65 µs/mol | 83.03 µs/mol | 6.1× |
| 1,000 | 10.39 µs/mol | 82.98 µs/mol | 8.0× |
| 10,000 | 12.58 µs/mol | 83.90 µs/mol | 6.7× |

`bulk.descriptors()` (full 55+ descriptor pipeline, incl. pKa/PAINS/ADMET): 906 µs/mol (N=100), 1,256 µs/mol (N=1,000).

**This does not reproduce the 2026-06 headline numbers** (3.6 µs/mol chematic / 20–50 µs/mol
RDKit / 5–14× — see [Notes](#notes)), even measured with the identical script, on hardware
that should be faster than the June M2 baseline, not slower.

### Large diverse corpus (5,000 unique ChEMBL-derived SMILES, `~/Downloads/SMILES.csv`)

| Task | chematic (`bulk.*`) | RDKit (serial, modern `rdFingerprintGenerator`) |
|------|----------------------|--------------------------------------------------|
| SMILES parse | **1.9 µs/mol** | — |
| ECFP4 fingerprint | **78.3 µs/mol** | ~163–234 µs/mol |
| Descriptor batch (55+ incl. ADMET/pKa/PAINS) | ~24.1 ms/mol | — |
| Tanimoto matrix (1000×1000) | 183.6 ms total | — |
| Standardisation | 2.06 ms/mol | — |

On unique, structurally diverse molecules, chematic's parallel batch ECFP4 is faster than
RDKit's serial loop but by roughly 2×, not 5–14×. This corpus is not directly comparable to
the small repeated-fixture table above (see [Notes](#notes)).

### How to reproduce

```bash
python scripts/benchmark_vs_rdkit.py --rdkit          # small-fixture table
python scripts/bench5k.py ~/Downloads/SMILES.csv       # accuracy only — no timing output despite the docs/benchmark.md pointer
```

## Throughput (native Rust, `cargo bench`)

10-molecule curated fixture (benzene, toluene, aspirin, caffeine, ibuprofen, pyridine, furan,
cyclohexane, paracetamol, glucose), single-threaded, no Python/PyO3 overhead.

| Benchmark | Time | Per-molecule |
|-----------|------|---------------|
| `ecfp4_10mol` (`chematic-fp`) | 931 µs – 1.11 ms / 10 mol | ~93–111 µs/mol |
| `find_sssr_10mol` (`chematic-perception`) | 411–492 µs / 10 mol | ~41–49 µs/mol |

`find_sssr` alone accounts for roughly half of `ecfp4`'s total cost on this fixture — every
`ecfp()` call runs one full SSSR pass to build initial atom invariants. See [Notes](#notes)
for why this is the leading candidate for the throughput gap.

```bash
cargo bench -p chematic-fp --bench ecfp_bench -- ecfp4_10mol
cargo bench -p chematic-perception --bench sssr_bench
```

## Notes

- **The 2026-06 throughput headline (3.6 µs/mol, 5–14×, RDKit 20–50 µs/mol) does not
  reproduce today**, on any of three independent measurements: the identical small-fixture
  script (12.6 µs/mol, 6.7×), a large diverse corpus (78.3 µs/mol Python bulk / 93–111 µs/mol
  pure-Rust serial), or RDKit's own reference number on the same hardware (84–234 µs/mol,
  itself 2–10× above the claimed 20–50 µs/mol baseline). Because RDKit's own number also
  moved, this is not simply "chematic got slower" — the corpus/methodology, or both
  implementations' dependency versions, changed since June. It has **not** been root-caused
  to a specific commit or isolated as a pure chematic regression in this snapshot.
- **A partial, evidence-backed mechanism**: `find_sssr` (SSSR ring perception) accounts for
  roughly half of `ecfp4`'s per-molecule cost on the pure-Rust fixture (~45 of ~100 µs/mol).
  `chematic-perception`'s SSSR implementation was substantively reworked for correctness this
  cycle (the "SSSR Horton fix", `19d3382` and preceding commits) — a plausible, not yet
  confirmed, contributor to any real throughput change since v0.4.20. `cargo bench`'s own
  regression flag on `find_sssr_polycyclic_5mol` (+93–104% vs its last stored baseline) is
  **not** treated as confirmation here — per the project's own finding
  ([issue #70](https://github.com/kent-tokyo/chematic/issues/70)), this repo's Criterion
  regression gate is measurement-broken (pseudo-replicated samples), so a "regressed" flag
  alone is not evidence. A proper `git bisect` against the criterion fixture is the natural
  follow-up, not attempted here.
- **`descriptors_array(smiles, columns)` computes the full ~55-descriptor pipeline (including
  ADMET, PAINS, and pKa SMARTS scans) regardless of the requested column list** — column
  selection only filters the returned dict, not the computation. A "7-column" batch therefore
  costs the same as the full `bulk.descriptors()` call (~20–24 ms/mol here); it is not
  comparable to the 2026-06 doc's "70-descriptor batch ~8 µs/mol" claim, which was almost
  certainly a different, much lighter computation (plain graph descriptors, no SMARTS
  catalogs) that no longer matches what `descriptors_array` does today.
- **`docs/benchmark.md`'s "How to reproduce" pointer for the ECFP4/descriptor throughput
  numbers (`scripts/rdkit_benchmark.py`) is stale** — that script measures RDKit alone (no
  chematic call at all) and was not run against `docs/benchmark_results.md`, which does not
  exist. The actual throughput reproduction path is `scripts/benchmark_vs_rdkit.py --rdkit`,
  used above. Similarly, `benchmarks/README.md`'s 175-mol accuracy reproduction command
  (`scripts/rdkit_benchmark.py`) does not perform an accuracy comparison — it is a pure
  RDKit-only timing script that happens to share the old script name. Not fixed in this
  snapshot; flagged for a follow-up doc-hygiene pass.
- The "3.6 µs/mol / 5–14×" and "504 KB" figures are repeated as marketing claims in `README.md`
  (7+ places), `docs/benchmark.md`, `docs/index.md`, `docs/rdkit_cheatsheet.md`, and
  `docs/rdkit-comparison.md`. None of those were edited as part of this snapshot — this file
  only records what was actually measured today; reconciling the public-facing claims is a
  separate decision.
- WASM per-operation timings (SMILES parse / ECFP4 / Tanimoto in-browser) were not
  re-measured this cycle — no Chrome harness was run. Only the bundle size was rebuilt and
  measured fresh. Treat the 2026-06 per-op numbers as unverified, not reconfirmed.
- Descriptor accuracy numbers are the one category that reproduces cleanly against both the
  2026-06 snapshot and `docs/validation.md` — same script, same corpus, consistent results.
- Aromaticity model unchanged from 2026-06: Hückel 4n+2 per SSSR ring independently; RDKit
  uses fused-ring electron delocalization. Differences visible in some N-heterocycles
  (pyridone, quinolone, indolizine).
