# Published 1.2.4 wheel, hard deadline, and fallback development

On macOS arm64 with Python 3.13, the published chematic 1.2.4 wheel and RDKit 2026.09.2 wheel were installed in separate directories. Every installed wheel file except pip's rewritten RECORD was checked byte-for-byte. Wheel, scorer, data and protocol hashes are in `2026-11-24-cod-published-freeze.json`. The 2,398-record COD set consists of previously unscored scaffold groups in the recorded repository history, excluding all groups touched by an aborted pilot. External use and tuning exposure are unknown. The invalid-exclusion audit used RDKit 2025.09.3 because the macOS 2026.09.2 wheel raised `bad any cast` during even a benzene Murcko scaffold extraction.

Each engine ran separately, alternating order per molecule. Both used 20 independent one-conformer attempts at seeds 42, 84, ... 840, MMFF 200 iterations and a final-gradient status check. The chematic profile used corrected gradients and 400 repair iterations. Stereo and geometry scoring was outside the timed generation. Raw status -1 RDKit candidates are retained as unoptimized and do not count as converged. Each per-engine failure remains in the denominator. For the fixed-count comparison, each engine had a 30-second cap per molecule, and only a completed 20-attempt run could count as fixed-count recovery. For the 0.2-second comparison, candidates received before the deadline were retained when the ongoing process was stopped. Worker creation, parsing and hydrogen addition were outside the generation timer. Termination and cleanup are included in the reported elapsed time. Peak child RSS is sampled at completed attempts and can miss a killed worker's true peak.

Screened recovery requires heavy-atom RMSD at most 1 Å and the strict declared-stereo and geometry screens. Intervals use 10,000 scaffold-cluster paired resamples and seed 42. In the 0.2 s run 20,992 chematic candidates had complete stereo results and zero contradicted or unevaluable declared stereo. In the fixed run 43,658 chematic candidates likewise had complete stereo results and zero contradicted or unevaluable declared stereo. The prespecified −2 pp noninferiority margin is met in the timed run and missed in the fixed-count run. The separate converged-only figures do not count missing MMFF parameters as successful optimization.

For fixed 20, 138 chematic B failures included 103 molecules recovered only by RDKit, and 45 Se failures included 13 recovered only by RDKit. None of those RDKit-only recoveries had a converged MMFF result. The opt-in Python fallback returns stereo-checked embedded coordinates as status −1 with energy `None` when the MMFF type assignment fails. It leaves the default error behavior intact. On 21 previously exposed B/Se development molecules, the fallback recovered 16, RDKit recovered 17, and neither converged on any. All 420 fallback candidates had strict stereo diagnostics with zero violations or unevaluable elements. See `2026-11-24-fallback-development.json`. This does not add MMFF parameters for these elements.

The first candidate holdout returned 767/1,197 timed recoveries versus 692 for RDKit, with a +4.65 to +7.93 pp interval. One reference could not be mapped by the original RMSD scorer, which prevented strict stereo records for 18 returned candidates, so the prespecified complete-coverage condition is not established. An exposed-case rerun showed that reversing the matching direction resolved its RMSD mapping, with zero strict stereo violations or unevaluable elements in 20 newly regenerated candidates. This does not reconstruct the missing original diagnostics. The later independent-scoring protocol and 1,189-row cohort were frozen before their evaluation in `2026-11-24-cod-v2-freeze.json`.

The fixed-count timing run overlapped briefly with a separate bootstrap summary calculation. Timings and memory are one-host observations and should not be generalized to other platforms. The evaluation harness measures the published native wheel with per-attempt process isolation. The product timeout API is an experimental Python addition to a repacked candidate wheel and needs its own acceptance evidence.
