## Toolchain and reproduction

- `wasm-pack 0.13.1`
- `wasm-opt version 130`
- gzip from the macOS host

```bash
cd crates/chematic-wasm
wasm-pack build --target web --release -d ../../demo/pkg/
cd ../..
wasm-opt -O3 -o demo/pkg/chematic_wasm_bg.wasm demo/pkg/chematic_wasm_bg.wasm
wc -c demo/pkg/chematic_wasm_bg.wasm
gzip -c -9 demo/pkg/chematic_wasm_bg.wasm | wc -c
shasum -a 256 demo/pkg/chematic_wasm_bg.wasm
```

Build outputs can vary with the Rust and Binaryen toolchains. Quote the byte
counts together with this date, toolchain, and digest.
