# Labute ASA and first-use ring-count follow-up

This record evaluates a source-built CheMatic v1.1.0 wheel after the Labute
ASA and RDKit-compatible ring-count hot paths were optimized. It is a bounded
single-host result, not a published-package or universal performance claim.

## Output gate

CheMatic and RDKit agree on all 10,000 rows for Labute ASA and ring count.
Labute ASA uses the record's `1e-9` numeric tolerance; ring count is exact.
TPSA and chiral Morgan also remain 10,000/10,000 equivalent in the same run.

## Timing result

The first 1,000 rows were measured in 41 alternating fresh-process blocks.
`prepared` excludes parsing and measures the first property call. `pipeline`
includes SMILES parsing and the property call. Ratios are RDKit time divided
by CheMatic time; a value above one favors CheMatic.

| Operation | Earlier prepared median | Candidate prepared median (95% CI) | Candidate parse-inclusive median (95% CI) |
|---|---:|---:|---:|
| Labute ASA | 0.664x | **1.713x** (1.689-1.752) | **7.422x** (7.293-7.589) |
| RDKit-compatible ring count | 0.028x | **1.216x** (1.160-1.256) | **7.779x** (7.645-7.842) |

Both optimized prepared lanes satisfy the repository speed-win policy because
their output gates pass and the lower bound of the paired 95% interval is
above one. The earlier measurements came from source commit `44338e16`; they
are included only as a before/after reference and were not run from the same
wheel as the candidate.

## Implementation boundary

- Python SMILES construction now prepares the same RDKit-parity aromatic/ring
  view needed by these descriptor calls. RDKit likewise performs ring and
  aromatic perception while constructing a sanitized molecule.
- RDKit-compatible ring count has a mutation-invalidated scalar cache, so the
  first Python property lookup does not rebuild an SSSR basis.
- Labute ASA reuses the prepared parity view rather than cloning and perceiving
  it on the first descriptor call.

These changes do not establish performance on other operating systems,
bindings, corpora, unsanitized molecules, or published v1.1.0 artifacts.
