# V3000 cross-engine canonical probe: v1.0.12

This bounded probe uses `benchmarks/fixtures/ethanol.v3000` (SHA-256
`64ac11b3de1c186deae555d54d6a47e7f3c72607ef0a90b0d93f467496bbd3ad`). The
three engines parse the same three-atom, two-bond V3000 topology.

| Engine | Canonical output | Structural result |
|---|---|---|
| schematic 1.0.12 | `C(C)O` | 3 atoms / 2 bonds |
| RDKit 2025.09.3 | `CCO` | 3 atoms / 2 bonds |
| Open Babel 3.2.1 | `CCO` | 3 atoms / 2 bonds |

The canonical strings are algorithm-specific and are not byte-identical. The
schematic output is accepted by RDKit and canonicalizes to the same `CCO`
structure. This is semantic round-trip evidence, not exact canonical-string
parity. Indigo was not installed in the local environment, so no Indigo claim
is made. SGROUP semantic cross-engine coverage remains open; the typed syntax
boundary is covered separately by the Node/WASM contract test.

Reproduce the schematic probe with:

```sh
cargo run -p chematic-cli --locked --offline -- convert \
  --input-format mol_v3000 --output-format smiles \
  --input benchmarks/fixtures/ethanol.v3000
```

RDKit and Open Babel reproduction commands are recorded in the accompanying
machine-readable result.
