[summary](../validation/results/734-754-followups-batch22-2026-10-08.json).

## Cheaper clash relief (identical output)

`write_mol` on 2,000 exposed-10k rows: 652M instructions at batch 21 →
**589M**. MOL blocks are byte-identical on all 15,000 exposed-10k and
ChEMBL-5k rows. The clash relief tries many moves per round and keeps the
one with fewest clashes, then crossings, then atoms moved. Three changes:

- **Clash count stops early.** A move's clash count only grows once the
  clashes it removes are subtracted. The count now stops as soon as it
  passes both the current drawing's and the best move's count.
- **Crossing count stops early.** At an equal clash count, the crossing
  count stops once it passes the bound. The bound is the best move's count
  (where a tie can still win on size), or the current drawing's.
- **Stacking check only when needed.** The check for a move that stacks two
  atoms runs only for a move about to become the best. It ran for every
  candidate.

Two smaller changes: the turn's 30° check uses the turned root before the
whole branch is turned, and the turns are an array, not boxed closures.

## Forks in long peptides

Components of more than 60 atoms that take the narrow forks used to relieve
their ±45° drawing only when, before relief, it did as well as the ±30°
one. Relieving it always cost 165M instructions on 2,000 rows (+25%), so
that was decided against in batch 19. With the cheaper relief it is now
done for every component.

Substituents of up to three atoms (a carboxyl) now take the turns past 60°
that batch 19 gave one- and two-atom groups. For three-atom groups the turn
must keep the hinge's bonds 60° apart. Requiring 90° gave no fixed row;
requiring 30° added 60 narrow atoms.

Two rows lose their crossings and none gains a defect: the
trifluoromethylbenzoyl peptide hydrazide (batch 20's worse row) and a
semicarbazide peptide. Narrow forks changed on 68 rows. `write_mol` with
both changes: **680M** (batch 21: 652M; batch 18: 679M).

New tests: `large_components_open_their_forks_too` (a 61-atom molecule with
no fork under 90°; it fails before this change) and the peptide hydrazide
in `bridged_and_crowded_layouts_have_no_clash_or_crossing`.

## Kept as decided

- **Chlorendic acid** (batch 20's other worse row). Its gem-dichloro bridge
  atom sits inside the norbornene outline, so one Cl crosses a ring bond
  whichever face it takes. The earlier crossing-free drawing came from the
  angle-ranking bug fixed in batch 20.
- **Slowest canonical SMILES rows.** ChEMBL-5k row 2984 spends 87% of its
  3.8 ms writing each candidate of the aromatic E/Z planner. Writing each
  candidate from one template would need the writer's token-orientation
  rules repeated outside it, a risk to canonical identity. The 333-atom
  peptide's cost is the generic rank refinement.
- **The WASM error surface** (batch 21, the maintainer's choice).
- **Fullerenes and octahedral complexes** (batches 18–19).
