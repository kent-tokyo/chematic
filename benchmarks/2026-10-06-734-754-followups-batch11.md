## RDKit's Kekulé structure

`Kekulize(mol, canonical=true)`, which RDKit's MMFF94 typer calls, walks an
aromatic system in RDKit's canonical atom-rank order and keeps the first
Kekulé structure it reaches. Fullerene cages have many; which hexagons end
up with three double bonds decides MMFF94's aromaticity pass. chematic's
own kekulization gives a valid structure, not that one.
`chematic_perception::rdkit_canonical_kekule` ports RDKit's
`rankFragmentAtoms` (`new_canon`: partition refinement, the special
chirality and symmetry passes, tie breaking) and `kekulizeWorker`; which
atoms take a double bond is read from chematic's own structure.

| RDKit 2026.03.6, explicit-H molecules on RDKit's aromatic view | Exposed 10k | ChEMBL 5k | Kekulé-written 15k |
|---|---:|---:|---:|
| Kekulé structure identical to `Kekulize(canonical=True)` (aromatic rows) | **7,957 / 7,957** | **4,637 / 4,637** | **12,594 / 12,594** |
| `CanonicalRankAtoms` identical, rows without E/Z | 9,428 / 9,428 | 4,482 / 4,482 | 13,910 / 13,910 |
| rows with E/Z (double-bond stereo is not ranked) | 400 / 572 | 350 / 518 | 750 / 1,090 |

Double-bond stereo only splits rank ties that Kekulé structures do not
depend on (every structure above matches).

## MMFF94 typing

| Heavy atoms typed differently from RDKit | v1.0.36 | Source |
|---|---:|---:|
| exposed 10k | 81 | **0** |
| ChEMBL 5k | 5 | **0** |
| Kekulé-written 15k | 39 | **0** |

Hydrogens: 0 everywhere. With RDKit's Kekulé structure the three fullerene
adducts type as RDKit (78 atoms). Nitrogen outside aromatic rings is now a
literal port of RDKit's branch, including its loop-carried state
(`elementDoubleBondedToC` is not reset between carbon neighbours, so a
neutral N between an imine carbon and a tri-aminated carbon is NGD+, 56),
the valence RDKit recomputes for N in an accepted MMFF ring (the porphyrin's
imine N: NM, 62), a sulfonyl azide N (imine/azo, 9), a sulfonylimine N (NSO,
48) and amidinium N on both ends (NCN+, 55); the imidazolium C2 is CIM+ (80).
The typer reads RDKit's ring list (its symmetrized SSSR in its order) and,
because `MolFromSmiles` perceives aromaticity whatever the input spelling,
kekulizes RDKit's aromatic view rather than a Kekulé input's own double
bonds. A calibrated rule that treated charged six-rings inside large
macrocycles as Kekulé is removed: the literal pass on RDKit's structure
gives RDKit's answer there (one of two quinolinium rings of a bis-quinolinium
macrocycle aromatic, the other not).

Cost: parsing, adding hydrogens and typing 2,000 rows takes 4.5% more
instructions than the v1.0.36 typer on aromatic-written input (1,412M →
1,475M) and 26% more on Kekulé-written input (1,324M → 1,674M), most of it
the canonical ranking of the explicit-H molecule that RDKit does too.

## RDKit's ring order

RDKit's SMILES parser creates ring-closure bonds after the whole string,
ordered by ring label, so they come last in its bond list and its SSSR
search meets them last. The parser now records each closure's label and
occurrence (`Molecule::rdkit_bond_order`, cleared by any edit that
renumbers bonds) and `rdkit_sssr_ring_order` walks bonds in that order.
It also skips the metal bonds `cleanUpOrganometallics` turns dative (a
four-bonded carbanion on Fe).

| exposed 10k (rows with rings) | 8,825 / 8,830 | **8,830 / 8,830** |
| ChEMBL 5k | 4,929 / 4,929 | 4,929 / 4,929 |

## Aromaticity on cages

RDKit's aromaticity runs over its symmetrized SSSR. On the Kekulé-written
fullerene adduct one hexagon is aromatic only through a ring
`symmetrizeSSSR` adds, so the RDKit-parity model now takes RDKit's rings
when an atom lies on three or more SSSR rings (cages); elsewhere it keeps
chematic's SSSR. `^n` on Kekulé-written copies: 134,999 → **135,000 /
135,000** cells. Parse plus perception of 3,000 rows: +1.9% instructions on
Kekulé-written input, unchanged on aromatic input.

## MOL writer

A layout that leaves a declared ring E/Z bond undrawable is now retried
with the atoms in reverse order, as an undrawable centre already was.
Bryostatin's macrocyclic trans bond is drawn on the second layout: RDKit
reads ChEMBL 5k back as written on **1,670 / 1,670** stereo rows (v1.0.36:
1,669) and `strict=True` refuses none (v1.0.36: one); Kekulé-written 15k
3,356 / 3,357 (3,355). Exposed 10k stays 1,686 / 1,687: the
bridgehead amine whose `@` chematic reads as OpenSMILES does (kept,
adjudicated in batch 9).

## Imine E/Z

The six imine rows that the v1.0.33 published record lists as E against
RDKit's Z (exposed 10k 1206, 1213, 1214, 1287, 1370, 1371; exocyclic C=N on
the ring-fusion carbon of an imidazo[1,2-a]pyridine) are default-mode
(`legacy`) labels. `cip_stereo(mode="accurate")` ranks double-bond ends
with the hierarchical digraph engine (#634) and labels them Z, as
`rdCIPLabeler` does:

| E/Z bonds vs `rdCIPLabeler` | Exposed 10k | ChEMBL 5k |
|---|---:|---:|
| accurate mode | **780 / 780** | **678 / 678** |
| legacy (default) mode | 770 / 780 | 678 / 678 |

The legacy engine stays unchanged, as its documentation promises; the
Python, Rust, WASM and example documentation that still said the accurate
mode takes E/Z from legacy is corrected.
