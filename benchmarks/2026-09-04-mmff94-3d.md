# MMFF94 / 3D pipeline benchmark — 2026-09-04

This local Criterion microbenchmark covers the v1.0.3 candidate. It is not a
cross-platform comparison and does not establish RDKit parity or replacement.

Environment: macOS arm64, Rust release benchmark profile, Criterion sample size
10, local cached dependencies.

| Operation | Fixture | Median |
| --- | --- | ---: |
| Prepared MMFF94 energy | 6 molecules | 22.5 µs |
| One-shot MMFF94 energy | 6 molecules | 365.2 µs |
| MMFF94 L-BFGS (8 iterations) | 6 molecules | 19.2 ms |
| ETKDG generation | 5 molecules | 1.28 ms |
| MMFF94 minimization | 5 molecules | 387.5 ms |

Prepared versus one-shot is a cache-effect comparison on the same fixture, not
an end-to-end application speedup.

```bash
cargo bench -p chematic-ff --bench mmff94_bench --offline -- --sample-size 10
cargo bench -p chematic-3d --bench pipeline_3d_bench --offline -- --sample-size 10
```
