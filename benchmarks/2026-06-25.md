## Descriptor accuracy vs RDKit 2026.03.3

### 175-mol drug-like corpus (in-repo: `scripts/rdkit_ref_properties.tsv`)

| Descriptor | Agreement | Threshold |

| Molecular weight | 100% | exact |

| TPSA | **100%** | ±0.1 Å² |

### 4,999-mol ChEMBL subset (external corpus, requires download)

| Descriptor | Agreement | Threshold |
|------------|-----------|-----------|
| HBA count | **100%** (4 999 / 4 999) | exact |
| HBD count | **100%** | exact |
| Aromatic ring count | **100%** | exact |
| TPSA | 93.3% | ±0.1 Å² |

TPSA gap on the large corpus: chematic uses the Ertl (2000) SMARTS-based algorithm matching
RDKit's `rdMolDescriptors.CalcTPSA`; residual 6.7% divergence is concentrated in
N-oxide and sulfonamide edge cases. On the 175-mol drug-like set (no sulfonamides, no N-oxides)
agreement is 100%.

### How to reproduce

# 5k corpus (requires ChEMBL SMILES CSV)
python scripts/bench5k.py ~/Downloads/SMILES.csv --detail

## Notes

- All chematic numbers use the stable release (`pip install chematic==0.4.20`)
- ECFP4 benchmark uses radius=2, 2048 bits — matching RDKit `AllChem.GetMorganFingerprintAsBitVect(mol, 2, 2048)`
- Aromaticity model: Hückel 4n+2 per SSSR ring independently; RDKit uses fused-ring electron delocalization. Differences visible in some N-heterocycles (pyridone, quinolone, indolizine).
