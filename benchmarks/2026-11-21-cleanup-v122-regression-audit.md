# Cleanup v1.2.2 regression audit

The fixed stress corpus, RDKit 2026.09.1 and v1.2.2 source dump reproduce 4,022 exact Cleanup strings among 4,069 compatible rows. The 47 previously exact rows have the following classification. The published macOS arm64 Python 3.13 wheel was checked against its archive before inspecting its in-memory results. The wheel output matches the source record on all 47 rows.

The published v1.2.2 recovery run's [retained job results](../validation/results/pypi-v1.2.2-published-gates-2026-11-21.json) identify its publication job, three runtime jobs and eleven chemistry jobs individually. The release checks validate the retained job set and artifact identities offline; the record is a snapshot of the completed GitHub run.

For 31 chemical differences, element, formal charge, attached hydrogen and connectivity do not match under graph isomorphism. A further row, 2025, matches RDKit after sanitization but both products lose one hydrogen from the input. Row 2203 is among the 31 graph differences and also loses one hydrogen in both products. For the remaining 15 rows, isotope and bond graphs match, and sanitizing a copy of RDKit's Cleanup product yields the same canonical isomeric SMILES as reparsing the chematic output. This result describes the sanitized products. The original RDKit product's radical state differs from the state inferred on parsing the chematic SMILES, and is retained in the row record. The graph, formula and repeat-Cleanup checks are in [cleanup-v1.2.2-47-atom-audit-2026-11-21.json](../validation/results/cleanup-v1.2.2-47-atom-audit-2026-11-21.json).

All 47 chematic outputs have the same recorded compatibility SMILES after a second Cleanup. RDKit's compatibility SMILES changes after a second Cleanup on 39 of the rows. The eight chemical differences whose RDKit output stays the same on a second Cleanup are indices 65, 83, 101, 809, 911, 1664, 2076 and 2855. Stability alone does not establish the correct chemical result.

For nine of the 31 graph differences, the second RDKit Cleanup string equals canonical SMILES obtained by reparsing the chematic output. The row record retains this separate check; it does not establish that the first in-memory RDKit product is the same molecule.

The record also contains six successive RDKit Cleanup strings per row. On those nine rows, the second, fourth and sixth applications each match the reparsed chematic output. This shows why copying the first result can conflict with a stable repeated-Cleanup contract on these inputs.

For each of those eight inputs, [cleanup-rooted-smiles-v1.2.2-2026-11-21.json](../validation/results/cleanup-rooted-smiles-v1.2.2-2026-11-21.json) records deterministic SMILES rooted at each atom. The two libraries parse every variant to the same canonical input. RDKit Cleanup returns between two and nine distinct strings per input, depending on atom order. The published chematic wheel returns one string per input. Choosing a single input ordering to imitate one RDKit result would change this observed representation invariance.

The same check across all 31 graph differences produced 797 distinct rooted inputs with no input-parsing exclusions. Chematic returned one output per molecule, while RDKit returned multiple outputs for 24 molecules. For 13 molecules, at least one rooted RDKit result exactly matches chematic. The full variants are in [cleanup-rooted-smiles-31-v1.2.2-2026-11-21.json](../validation/results/cleanup-rooted-smiles-31-v1.2.2-2026-11-21.json). These observations establish stability on these spellings; chemical correctness must be evaluated separately for each case.

An experiment using RDKit's first proposed acid/base transfer fixed 24 stress-string differences and both prior regressions in the 10,000-row corpus. Four existing tests failed, covering acid strength, Kekulé and aromatic forms, a zinc-cut conjugate base, and ferrocene ions. The experiment was reverted. Input-order, query-embedding-order and RDKit-compatible atom-rank experiments introduced new mismatches and were also reverted. Their rows, counts and source hashes are in [cleanup-order-experiments-2026-11-21.json](../validation/results/cleanup-order-experiments-2026-11-21.json) and its linked reports. The remaining chemical differences still need a fix or an explicit supported-policy decision.
