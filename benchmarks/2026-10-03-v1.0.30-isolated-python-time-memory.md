# Published Python isolated time and process-RSS lanes (2026-10-03)

This is an exposed, single-host, bounded operation comparison. It adds a
fresh-process memory axis to the existing paired timings; it does **not**
close roadmap P0.2 for every operation and binding.

## Provenance and protocol

- Apple M4, macOS 27.0.1 arm64, CPython 3.13.6. The exposed
  [5,000-row ChEMBL corpus](../scripts/chembl_accuracy_corpus_4999.smi) has
  SHA-256 `1c47371dcbe37f4e0a141bf545b72bf238de2761fa3894fa251a552d84728d3e`.
- Published wheel SHA-256: CheMatic 1.0.29
  `a9ceb3c685e6cf4abbbdb1ae1cdbaa76b9ba13c8015d53750ba617cba3f7c1d8`,
  CheMatic 1.0.30
  `f6b1b22dd898cf3f100001156d9504b3753cb6b392143cbc0e6f3be78ec723d5`,
  RDKit 2026.03.6
  `e16c467cb254a223e59a0cf81358c6b39da15a99d2909170d693e95778fddb41`.
  The runner checks each supplied artifact hash and imported runtime version.
  Paths to the installed interpreters are retained in the raw records; this
  local run does not independently attest the bytes installed in each venv.
- [Runner](../scripts/bench_published_python_isolated_paired.py): 20 AB/BA
  alternating paired blocks; a fresh interpreter for each arm of every
  block; one separate molecule instance for warmup; full per-arm output SHA-256 checked
  against its archived published-wheel 63-operation output. A 4,000-resample
  paired bootstrap gives the median-ratio 95% interval. No failed output is
  silently counted as a speed observation.
- Timed interval covers only the named operation. `parse_inclusive` includes
  SMILES parsing; `prepared_first_use` parses outside the timer, then times
  first property access; `precomputed` parses and accesses the property once
  before timing repeated access. Per-block setup times are retained.
  RDKit computes more perception during parse; the prepared-first-use
  interval alone is **not** equal work.
- RSS is the fresh worker process's `ru_maxrss` high-water mark, including
  Python/RDKit imports, preparation, operation, and retained result objects.
  It is reported separately from time. It is neither incremental operation
  allocation nor unique physical memory, and no cross-binding memory
  superiority is inferred from it.

The table's time ratio is arm A / arm B (>1 means B faster); RSS ratio is
whole-process A / B (>1 means B lower). All intervals are paired-bootstrap
95% intervals over the 20 retained blocks.

For the prepared-first-use Morgan lane, the median untimed parse/setup is
541.0 ms on RDKit versus 25.4 ms on CheMatic; the median timed first access
is about 181 ms versus 61 ms. These stages must be kept together before an
end-to-end interpretation. The parse-inclusive lane is the separately
measured combined task. A large RSS ratio here mostly describes the full
Python process with its imported library and result representation; it is
not a million-molecule scaling estimate.

Run `python3 scripts/check_published_python_isolated_paired.py` to verify
all archived arm versions, artifact and output hashes, 20 alternating block
orders, 5,000 indices, paired intervals, and no-claim classifications. To
reproduce one lane, use the runner with the exact wheel files, separate
installed interpreters, the archived per-version output files as
`--reference-a` and `--reference-b`, `--blocks 20`, and the operation/mode
shown above. Other hardware, RDKit versions, or datasets require a new
dated record rather than inheriting these ratios.
