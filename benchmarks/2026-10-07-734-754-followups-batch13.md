## MMFF94 energies on both corpora

Every single-fragment row of the exposed 10k and ChEMBL 5k that RDKit can
parameterize (14,684 of 15,000; 180 RDKit-unsupported, 136 multi-fragment), on
RDKit's 2D coordinates scaled by 1.5 with a random z in ±0.4 Å, each term
from an `MMFFMolProperties` with only that term on:

| Rows differing from RDKit by more than a relative 1e-9 | Batch 12 | Source |
|---|---:|---:|
| bond | 0 | 0 |
| angle | 1 | 0 |
| stretch-bend | 1 | 0 |
| out-of-plane | 34 | 0 |
| torsion | 0 | 0 |
| van der Waals | 3 | 0 |
| electrostatics | 8 | 0 |

The three van der Waals rows of batch 12 had coincident atoms in the 2D
layout (RDKit keeps such a pair; chematic skipped pairs closer than
0.01 Å), and the electrostatic rows include pairs over 100 Å apart (below).
The largest relative difference on any term is now 3.0e-13.

Causes, each checked against RDKit's source and values:

- **Partial charges:** RDKit's `computeMMFFCharges` shares a formal charge
  among O2CM/SM oxygens and sulfurs of a carboxylate, sulfonate, phosphonate
  or thiocarboxylate head (types 32, 72), among the N5M nitrogens of an
  anionic five-ring (76), and among the nitrogens of a conjugated amidinium
  or imidazolium cation (55, 56, 81); N=N+ next to a diazonium N (61) is +1.
  chematic did not share them, which changed the partial charges and so
  the electrostatics (the N-oxide, sulfinate, imidazolium and phosphazene
  rows).
- **Out-of-plane centres:** RDKit gives an out-of-plane term to every
  three-connected atom its table covers; types 8, 17, 26, 55, 69 and 73 were
  missing from chematic's list.
- **Angles:** RDKit's angle lookup stops after its four equivalence levels
  and then uses Halgren's empirical rule; chematic retried at angle type 0
  (a four-ring 3-40-20 angle took the open-chain row's θ₀ 112° instead of
  the rule's 90°).
- **Non-bonded cut-off:** RDKit's `nonBondedThresh` (100 Å) leaves out
  van der Waals and electrostatic pairs farther apart; chematic now does
  too (energy and gradient). It matters only on stretched geometries.

The per-term lane (265 molecules, 262 comparable, RDKit's 3D coordinates;
[rows](../validation/results/mmff94-same-explicit-h-energy-per-term-batch13-2026-10-07.jsonl))
is unchanged from batch 12: total median 8.5e-14, max 1.9e-12 kcal/mol; the
analytic gradient is within a scaled 1.7e-6 of a central difference on rows
166, 178 and 231.

### Salts

RDKit's `MMFFGetMoleculeForceField` leaves out van der Waals and
electrostatic pairs between fragments (`ignoreInterfragInteractions=True`).
The default stays as it was (chematic keeps them, so a minimized salt's
fragments cannot overlap). The new `Mmff94Options {
ignore_interfragment_interactions }` (`Mmff94EnergyModel::new_with_options`,
`mmff94_energy_breakdown_with_options`; Python
`mmff94_energy_breakdown(..., ignore_interfrag_interactions=True)` and
`mmff94_total_energy`; WASM `mmff94EnergyBreakdownFromCoordsJsonWithOptions`)
gives RDKit's numbers: every multi-fragment row RDKit can parameterize
(102 of 136) agrees term by term.

## RDKit's minimizer

`Mmff94EnergyModel::minimize_bfgs` is a port of RDKit's `BFGSOpt::minimize`
as `ForceField::minimize` calls it: dense inverse Hessian, the Numerical
Recipes line search with its quadratic/cubic backtracking, and RDKit's
gradient scaling (0.1, halved while a component exceeds 10). From the same
262 RDKit ETKDG starts as RDKit:

| | RDKit `Minimize(maxIts=200)` | port, RDKit's test (`Mmff94Convergence::Rdkit`) |
|---|---:|---:|
| energy after 200 iterations, abs. difference | — | median 1.9e-13, p90 5.1e-9, max 0.068 kcal/mol |
| converged | 140 | 140 (262 / 262 rows agree) |

RDKit's convergence test is relative (`max |g| max(|x|, 1) / max(|E|, 1)`
on its scaled gradient), so a converged RDKit run keeps residual forces well
above 1e-4 kcal/mol/Å (median 0.0034). Run to chematic's absolute test
(`Mmff94Convergence::MaxGradient(1e-4)`, which also caps each line search's
first step at 0.3 Å per coordinate, `BFGS_MAX_COORDINATE_STEP`):

| To max \|g\| < 1e-4 | chematic L-BFGS (batch 12) | BFGS |
|---|---:|---:|
| converged at all | 262 | 262 |
| iterations, median / p90 | 356.5 / 1,414 | 192.5 / 449 |
| converged within 200 | 77 | 136 |
| time, all rows | 43.5 s | 22.8 s |
| final energy vs L-BFGS | — | same (≤1e-3) 235, lower 11, higher 16 |
| final energy vs RDKit run to convergence | — | same 254, lower 4, higher 4 |

The two minimizers reach the same minimum on most rows; where they differ
they found different local minima. Molecules over 500 atoms
(`BFGS_DENSE_MAX_ATOMS`) keep L-BFGS, so memory stays bounded.

### 3D pipeline (A6, 265 molecules, stereo-safe MMFF94 arm, external scorer)

The MMFF94 bridge now minimizes with BFGS. RDKit's long first steps (several
Å) relaxed four β-lactam ring fusions (penam sulfones, one sulfoxide)

Rule 5 now covers a saturated ring centre with a lone pair (N, P, As, S+,
Se+) whose two ring arms are enantiomorphic, with RDKit's reading of the
spelling (batch 12): RDKit's `r`/`s`. On 1,120 RDKit-written spellings of

## Canonical SMILES: worst cases

30,305 inputs: both corpora as written and as explicit-H random spellings,
23 symmetric molecules (C60, C60H60, dodecahedrane, cubane, coronene,
kekulene, phthalocyanine, α-cyclodextrin, β-carotene, a tetra-tert-butyl
dendrimer, ten benzenes, …) as written, explicit-H and in four random
spellings, and synthetic cages (random cubic carbon graphs of 20–200 atoms,
prisms of 6–48 rings, tori of 4×4–10×10).

| | Batch 12 | Source |
|---|---:|---:|
| random cubic graph, 60 atoms | 3.3–8.8 s | 3 ms |
| random cubic graph, 100 / 200 atoms | > 20 s (stopped) | 10 / 41 ms |
| torus 10×10 | 0.78 s | 0.3 s |
| slowest synthetic input | > 20 s | 61 ms |
| both corpora, all spellings (instructions) | 37.15 G | 37.42 G (+0.7%) |

The orbit-pruning search tested every pair of a large cell for an
automorphism, and on rigid graphs each test ran to its 200,000-step cap
(1,770 failed tests on 60 atoms). A pair is now first compared by an
invariant of the two branches (the refined ranks' labelled quotient):
members of one orbit always agree, so a mismatch settles the pair without
search; when both branches are discrete the rank-matching map is checked
directly, and the remaining search is restricted to maps that respect both
branches' refined ranks. Small cells keep the short search first, which is
cheaper there. Canonical SMILES are identical on all 30,305 inputs, and
every molecule's spellings give one string.

The slowest corpus row is exposed 10k row 4903 (a squaraine bis-imine with
two ring E/Z bonds): 50–80 ms, against RDKit's 0.17 ms. The writer's E/Z
marker planner writes and re-parses 2,916 candidate strings for it; that
stays open. RDKit writes the 10k as-written corpus in 0.81 s, chematic in
0.80 s.

## Cost of MMFF94 typing

Parse, add hydrogens and type 2,000 rows (instructions, callgrind):

| | v1.0.36 | Batch 12 | Source (vs v1.0.36) |
|---|---:|---:|---:|
| aromatic-written | 1,391M | 1,237M | **1,091M** (−22%) |
| Kekulé-written | 1,311M | 1,451M | **1,303M** (−0.6%) |

The MMFF aromatic view is now `kmol` changed in place when its adjacency is
already in bond order (it rebuilt the molecule bond by bond); RDKit's
canonical ranking and the SSSR port keep per-atom neighbour lists inline
(`SmallVec`) and reuse their breadth-first buffers. Types are unchanged:
0 heavy atoms and 0 hydrogens differ from RDKit on all three corpora.

## RDKit 2026.09.1 ring counts

`find_matches_rdkit_parity(smarts, profile="2026.09.1")` (Rust:
`RdkitParityConfig { ring_count_model: RdkitRingCountModel::RelevantCycles }`)
counts `[R<n>]` in RDKit 2026.09.1's ring list: every relevant cycle, the
union of all minimum cycle bases (new `chematic_perception::relevant_cycles`,
Vismara's algorithm). On the 310,000-cell grid against the native RDKit
2026.09.1 build's cells
([report](../validation/results/smarts-310k-rdkit-2026-09-1-profile-batch13-2026-10-07.json)):

| Profile | Exact | Typed refusals | Wrong |
|---|---:|---:|---:|
| `"2026.03.6"` (default) | 309,982 | 18 (`ring_model_ambiguous`) | 0 |
| `"2026.09.1"` | **310,000** | 0 | 0 |

The relevant-cycle list does not depend on atom order, so nothing is
refused as ambiguous. Bonds to metals are ring bonds there as in RDKit (a
first version that left out organometallic bonds got two cells of a copper
bis-chelate wrong). `scripts/check_python_smarts_parity_310k_rdkit_2026_09_1.py`
is the gate.

## Harness

The WASM Node tests still need the `wasm32` target, which neither this host
nor the linked VM can download (static.rust-lang.org and conda-forge are
blocked); CI's `test-wasm` runs them. `published_wheel_chemistry_gates.py`
gains `--resume` (a rerun skips every step whose JSON output is complete)
and `--corpus-shards N` (the BioTransformer corpus runs as N reactant
shards, each its own process and resumable output, and their counts are
added up), so a host that ends long-lived processes reruns the same command
until it is done instead of hand-sharding. One (rule, reactant) pair of the
v1.0.36 wheel (BTMR1063 on tri(dodecylthio)methane, about 175 s) still
needs a host that lets one process run that long.
